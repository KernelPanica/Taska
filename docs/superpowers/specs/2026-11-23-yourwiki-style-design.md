# YourTask: оформление YourWiki

Запрос: проверить код и интерфейс Playwright/TypeUI, исправить вёрстку и повторить визуальный язык YourWiki. Эталон — действующий https://wiki.ageofsilence.net и его исходные `apps/web/src/enterprise.css`, `layout-spacing.css`, `workspace-layout.css`.

Перенести точные цвета светлой/тёмной тем, автоматический выбор по системной теме, IBM Plex Sans, размеры контролов 44 px, радиусы 8/12 px, состояния фокуса и активных разделов. Экран входа — одна центральная карточка шириной 440 px, как у YourWiki; оба существующих способа входа и RU/EN сохраняются. Рабочие экраны сохраняют свою структуру задач и боковую навигацию, но используют одинаковые поверхности, границы, типографику и отступы. Не переносить в YourTask навигацию по документам YourWiki.

Проверки: основные страницы на ширинах 1440/768/390, обе темы, длинные подписи, формы, таблицы со своей прокруткой, доска со своей горизонтальной прокруткой, меню, клавиатура, вход. Не менять API, права и данные. После проверки обновить существующий сайт на wiki-new по уже используемой процедуре релизов: отдельный образ, проверка миграций на копии, полный snapshot тома перед переключением, сохранение прежнего образа и конфигурации.

Выбор реализации: сопоставить существующие семантические CSS-токены с исходными токенами YourWiki и исправить базовые правила на месте; это сохраняет существующие компоненты и не создаёт второй конкурирующий слой стилей. Первичные скриншоты находятся в output/playwright.

## Проверки и решения

- MCP TypeUI подключён через авторизованный Streamable HTTP после OAuth-входа; использованы официальные TypeUI Fundamentals (accessibility, spacing, typography, UI и UX principles). Оригинальные файлы прочитаны из официального репозитория во временном каталоге. Проектные данные во внешний сервис не отправлялись.
- Для конкретных размеров и визуального языка выбран действующий YourWiki, а не общие рекомендации TypeUI для маркетинговых страниц: заголовок входа 28px/1.2, отступ до описания 16px, рабочие заголовки 20px/1.3.
- Единственное небольшое отличие в палитре: светлая граница контрола #838b99 вместо #858d9b. Это сохраняет оттенок и даёт контраст 3.03:1 на фоне поля #edf1f7; исходный цвет давал 2.95:1.
- Основной обход: 71 сочетание страницы/темы/ширины, без ошибок JavaScript и переполнения документа. Вложенные формы: 54 сочетания; найдена и исправлена сетка схемы статусов на 320px (переполнение 48px). После исправления проверены обе темы и 320/390/768/1440px, переполнение 0.
- Проверены RU/EN, клавиатурное управление переключателем сайтов (Enter, стрелки, Esc и возврат фокуса), создание локального тикета с длинным названием, ссылка входа и её hover после завершения CSS-перехода. Изменения проверены отдельным ревьюером; дефект контраста primary-ссылки при наведении исправлен.
- Артефакты проверок: output/playwright/layout-after.json, detail-layout.json, contrast.json, login-check.json и скриншоты before/after. Полное соответствие WCAG и проверка всех браузеров не заявляются.
