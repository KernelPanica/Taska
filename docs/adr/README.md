# Каталог технических решений (ADR)

Каждое значимое техническое решение YourTask записывается отдельным файлом: контекст, решение, последствия, ссылки на требования.
Новый ADR — следующий номер, статус «Предложено» → «Принято». Принятые решения не переписываются: их заменяют новым ADR со ссылкой.

Источники требований: «YourSpace — требования», версия от 16.11.2026 (R-…), и «YourSpace — карточки» (YS-…, YT-…). Термины в коде и API — по глоссарию требований (раздел 1): колодец — `guild`, фичекоманда — `feature team`, суперадмин — `superadmin`.
