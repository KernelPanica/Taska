# 0006. Тестовые данные изолированы флагом

- Статус: принято, 2026-11-16
- Требования: карточка, п. 7

## Решение

- Тестовое пространство (`slug: test`) и тестовые пользователи создаются идемпотентным сидом при старте в профилях `development` и `test` (и `npm run db:seed`). В `production` сид запрещён.
- У пространств, пользователей, колодцев, фичекоманд и измерений есть флаг `is_test`. Правило видимости: **обычные пользователи тестовых сущностей не видят; тестовые видят всё**. Всё, что создаёт тестовый пользователь, тоже помечается тестовым.
  _Изменено в YT-02:_ раньше правило было симметричным (тестовые не видели реальных). Тогда тестовый суперадмин в разработке не видел бы стартовых пространств «Дирекция», «Core»… из миграции. В production тестовых пользователей нет, поэтому послабление ничего не открывает.
- Тестовые аккаунты (`apps/api/src/testing/accounts.ts`) общие для заглушки YourSpace и сида; пароль и код второй проверки живут только «на стороне YourSpace».

| Логин         | Роль       | Google                  | Вторая проверка | Назначение                            |
| ------------- | ---------- | ----------------------- | --------------- | ------------------------------------- |
| `anna`        | участник   | `anna.test@gmail.test`  | —               | вход паролем и через Google           |
| `ben`         | участник   | —                       | —               | английский язык в профиле             |
| `admin`       | суперадмин | `admin.test@gmail.test` | `123456`        | вход суперадмина со второй проверкой  |
| `admin-no2fa` | суперадмин | —                       | —               | отказ суперадмину без второй проверки |
| `vera`        | обычный    | —                       | —               | не тестовый: не видит тестовых данных |

Пароль всех тестовых аккаунтов — `yourspace`.

Сид также заводит тестовую структуру: фичекоманды «Совы», «Ежи», «Лисы» с ПМами, колодцы «Арт», «Анимация», «Программирование», «Тестирование», «Звук», «Аналитика» с лидами и шесть людей без аккаунта YourSpace. `anna` состоит в двух командах и ни в одном колодце. Если такая команда или колодец уже есть, сид их не трогает: ручные правки сохраняются.

## Последствия

- Каждый новый список/поиск сущностей обязан фильтровать по `is_test` зрителя.
