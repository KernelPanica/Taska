# 0005. Интерфейс на русском и английском

- Статус: принято, 2026-11-16
- Требования: карточка, п. 4

## Решение

- Собственный лёгкий модуль `apps/web/src/i18n` без внешних библиотек: словари `ru.ts` (эталон ключей) и `en.ts` (тип `Record<MessageKey, string>` — пропущенный ключ не скомпилируется), подстановка `{param}`.
- Язык хранится **в профиле** (`users.locale`, `PATCH /api/v1/me`). До входа — сохранённый выбор, затем язык браузера, по умолчанию русский. После входа язык профиля главнее.
- Переключатель RU/EN есть на странице входа и в шапке приложения; `<html lang>` обновляется.
- Сервер отдаёт ошибки на английском + `code`; переводит интерфейс.

## Последствия

- Тест проверяет совпадение ключей словарей и наличие перевода для каждого кода ошибки.
- Третий язык — новый словарь и значение в `LOCALES` + миграция CHECK-ограничения.
